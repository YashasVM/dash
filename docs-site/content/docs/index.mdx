Documentation for seven small software products. Each product has its own page so setup notes, limits, and links stay easy to update.

## Products

- [OpenStream](./products/openstream) — Android camera to OBS over local Wi-Fi.
- [HOLEN](./products/holen) — Private downloads on Android or terminal.
- [Wisper Low](./products/wisper-low) — Local-first Windows dictation.
- [cd](./products/cd) — Direct browser-to-browser file sharing.
- [yt-cmd](./products/yt-cmd) — Interactive YouTube downloads in your terminal.
- [Img-gen](./products/img-gen) — Local browser background remover.
- [localhost](./products/localhost) — Public status page for local services.

## Source of truth

These pages are short operational guides. Release-specific behavior belongs in each product's GitHub repository.
