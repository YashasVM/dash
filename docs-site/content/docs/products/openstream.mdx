## What it does

OpenStream sends an Android phone camera into OBS Studio over local Wi-Fi. It uses SRT transport, hardware encoding, audio, discovery, and camera slots for multi-camera setups.

**Status:** Beta

## Quick start

1. Install the Android APK from [GitHub Releases](https://github.com/YashasVM/OpenStream/releases).
2. Install the Windows OBS plugin on the PC running OBS.
3. Put the phone and OBS PC on the same LAN.
4. Add an `OpenStream V8` source in OBS.
5. Open the Android app and pair it with an available camera slot.

Use a 5 GHz or Wi-Fi 6 network for lower latency. Guest Wi-Fi, VPNs, and client isolation can block discovery.
