## What it does

The localhost dashboard checks configured local services through its status endpoint and reports which ones are reachable.

**Status:** Live

## Quick start

Open the [status page](https://yvmx.dpdns.org/) and use the service list to see current reachability. A service must be reachable from the host running the status check to report online.
