## What it does

Wisper Low listens when you trigger a hotkey, transcribes locally, cleans up the text, and pastes it into the active app. Optional Ollama support can improve rewriting.

**Status:** Prototype release

## Quick start

1. Download the Windows installer from the [v0.1 release](https://github.com/YashasVM/Wisper-Low/releases/tag/v0.1).
2. Launch Wisper Low from the Start Menu.
3. Press `Ctrl+Alt+P` or `Ctrl+Alt+Space` to start dictation.
4. Press the same hotkey to stop and paste the cleaned text.

Press `Ctrl+Alt+Backspace` to cancel without pasting.

## Notes

Expect rough edges with microphone devices, hotkey conflicts, and model latency on slower machines. Windows SmartScreen may warn because the prototype is not code-signed.
