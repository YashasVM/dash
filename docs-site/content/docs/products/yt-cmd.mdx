## What it does

`yt-cmd` wraps `yt-dlp` in a terminal UI. Paste a YouTube URL, pick a quality, and download without memorizing flags.

**Status:** Active

## Quick start

Run it in an interactive terminal:

```bash
npx yt-cmd
```

Or use `bunx yt-cmd` or `npx yvm-yt`.

Video downloads prefer MP4 and fall back to MKV. Audio downloads are MP3. The app checks for `yt-dlp` and `ffmpeg` and can offer to install missing dependencies.
