cd

/di·rect/
direct browser-to-browser file transfer

Send a file straight from your browser — or your terminal — to someone else's. No cloud detour.

Pick a file, share a short code or QR link, keep both tabs open until it lands. Files are never intentionally stored by CD. Agents and terminals use cdx and land in the same orange receiver.

Three ways to send

01
Browser → BrowserWebRTC

Choose files on cd.yash0.in, share a word code like river, a link, or QR. Bytes travel over an encrypted WebRTC data channel.

Try it ↗ Terminal → Browsercdx send

Run cdx send ./app.apk, get a 5-digit code like 48291. Receiver types it into any browser. Exit 0 = verified bytes.

cdx.yash0.in ↗ Browser → Terminal/send relay

Open /send, pick one file, share the code. Receiver runs cdx receive <code>. Live relay, no stored copy.

Terminal flow

02
you send 
$ cdx send ./demo.mp4
48291

stdout is only the code — pipe-friendly. Progress goes to stderr. Keep cdx running while they download.

they receive 
$ cdx receive 48291
saved demo.mp4 (24.1 MB)

Or type 48291 into the Receive box on any browser. Codes expire after 15 min, one receiver.

cdx send ./fileshare one file, print a 5-digit code
cdx send --link ./secrets.zipprivate-link mode — full URL is the secret, end-to-end encrypted
cdx receive 48291pull the file to your terminal, verify byte count
cdx send --json ./filestructured output for agents and scripts

Short codes trade E2E for typability — TLS + live relay carry the trust, anyone guessing an active code can grab it. For sensitive files, use --link: the key stays in the URL fragment, never sent to the server.

Spec
Both tabs must stay open?

Yes. Keep both devices awake on a stable network, don't close or refresh mid-transfer. For huge files, split the archive or use a LAN tool.

Code won't connect?

Refresh both sides for a fresh code, drop the VPN, avoid guest/corporate networks that block WebRTC.

PATH warning after install?

Add ~/.local/bin to PATH, then run cdx send <file>. Or re-install with CDX_INSTALL_DIR pointed somewhere already on PATH.
